# Tivi Remote Updates

Signed, key-free APK downloads for Tivi Remote. Independent project, not affiliated with TiviMate or OpenAI.

Download `tivi-remote.apk` from the latest release and install over the existing app, without uninstalling. Saved TV connections and API keys are retained. Fresh installs require your own OpenAI API key for AI features; manual controls do not.

Updates check automatically when the app opens and download over Wi-Fi when idle. Android requires installation approval. No GitHub login is needed for updates.

Source code, personal builds and diagnostic reports are not hosted here. Diagnostic sharing is optional and goes only to the separate private source repository using a token configured on the phone. Do not post keys or diagnostic data in this public repository.
